# Jogo de Nave (Space Shooter Game)

Um clássico jogo de tiro espacial desenvolvido com Pygame. O jogador controla uma nave e deve destruir os inimigos que se aproximam, incluindo um chefe. O jogo apresenta power-ups, vários níveis e um sistema de pontuação.

## Funcionalidades

*   Nave controlada pelo jogador com capacidade de movimento e tiro.
*   Vários níveis com dificuldade crescente.
*   Diferentes tipos de inimigos com comportamentos únicos.
*   Luta com o chefe no final de cada nível.
*   Power-ups: escudo, tiro duplo, aumento de velocidade e muito mais.
*   Sistema de pontuação baseado nos inimigos destruídos.
*   Telas de game over e pausa.

## Como Executar

1.  Certifique-se de ter o Python e o Pygame instalados.
2.  Clone o repositório: `git clone https://github.com/ErickdeOliveiraBessaXavier/Jogo_Nave.git`
3.  Navegue até o diretório do projeto: `cd Jogo_Nave`
4.  Execute o jogo: `python run.py`

## Controles

*   **Setas ou WASD:** Mover a nave.
*   **Barra de espaço ou Enter:** Atirar.
*   **P:** Pausar o jogo.
*   **R:** Reiniciar o jogo após o game over.

## Tecnologias Utilizadas

*   Python
*   Pygame
