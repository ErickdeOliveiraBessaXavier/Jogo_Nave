PROBLEMA 4 — playing.py linhas 681, 690, 702, 714, 795, 808, 821
"list[Meteor | Alien | ...] is not assignable to list[Enemy]"
-----------------------------------------------------------

As funções de colisão em collisions.py declaram o parâmetro como
list[Enemy], mas o Pylance trata list como invariante.

SOLUÇÃO: Mude a assinatura de todas as funções afetadas em collisions.py
de list[Enemy] para Sequence[Enemy]:

Funções a alterar:
  - bullets_vs_enemies
  - mini_ship_bullets_vs_enemies
  - player_lasers_vs_enemies
  - check_mine_explosions
  - explosive_effects_vs_enemies
  - air_strike_bombs_vs_enemies
  - cannon_mines_vs_enemies

Troque o import e a assinatura:

    # No topo do arquivo já existe: from typing import Sequence
    # Apenas mude o parâmetro:

    def bullets_vs_enemies(
        self,
        ...,
        enemies: Sequence[Enemy],   # era list[Enemy]
        ...
    )

ATENÇÃO: Se dentro dessas funções você chama enemies[:] ou
enemies.extend(), Sequence não suporta isso.
- enemies[:] → list(enemies)  (para fazer cópia)
- enemies.extend() → não é possível; mantenha list[Enemy] nesse caso
  e use cast() na chamada do playing.py em vez de mudar a assinatura.

SOLUÇÃO ALTERNATIVA (sem mudar collisions.py):
No playing.py, faça cast antes de passar a lista:

    from typing import cast
    from ..systems.collisions import Enemy
    # ...
    self.collisions.bullets_vs_enemies(
        ...,
        cast(list[Enemy], self.entity_manager.enemies),
        ...
    )

Repita o cast nas 7 chamadas problemáticas.
