```python
def _start_coordinated_entry_animation(self) -> None:
    """
    Animação de entrada coordenada:
    - Coluna direita: blocos entram de baixo para cima
    - Coluna esquerda: blocos entram de cima para baixo
    - Efeito de convergência no centro
    """
    base_delay = 0.08  # Delay entre cada bloco
    
    for block in self._all_blocks:
        block.health = block.MAX_HEALTH
        block.dead = False
        block._hit_flash = 0.0
        block._rotation_angle = random.uniform(0.0, 360.0)
        block._rotation_dir = random.choice((-1.0, 1.0))
        sprite_frames = block._load_animation_frames(block.w, block.h)
        block._sprite_frame = random.choice(sprite_frames) if sprite_frames else None
        block._swap_active = False
        block._particles.clear()
        
        # Configurar animação de entrada com delay progressivo
        block._entry_anim_active = True
        block._entry_anim_duration = 0.85
        
        # COLUNA DIREITA: delay crescente de baixo pra cima
        if block.side == "right":
            # Bloco inferior (row_index alto) entra primeiro
            delay = (self.BLOCK_COUNT - 1 - block.row_index) * base_delay
        # COLUNA ESQUERDA: delay crescente de cima pra baixo
        else:
            # Bloco superior (row_index 0) entra primeiro
            delay = block.row_index * base_delay
        
        block._entry_anim_timer = -delay  # Negativo = aguardar antes de começar
        
        # Posição inicial fora da tela
        screen_w = Config.SCREEN_WIDTH
        if block.side == "left":
            block.cx = -block.RADIUS * 2.5
        else:
            block.cx = screen_w + block.RADIUS * 2.5
        block.cy = block._origin_cy
        block.x = block.cx - block.RADIUS
        block.y = block.cy - block.RADIUS
        block._rect.x = int(block.x)
        block._rect.y = int(block.y)
```

## 🎯 **RESUMO DA LÓGICA:**

1. **Entrada coordenada**: cada bloco tem um `_entry_anim_timer` negativo que funciona como delay. Direita entra de baixo pra cima, esquerda de cima pra baixo.

2. **Após a entrada**: quando todos os blocos terminam, ativa `_loop_movement_enabled = True`.

3. **Loop infinito**: todos os `_origin_cy` são decrementados continuamente. Quando um bloco sai do topo (cy < -RADIUS), ele é reposicionado na base (cy = SCREEN_HEIGHT + offset).
