# Revisão Técnica Crítica - Space Shooter

Itens pendentes após implementação do Event Bus e seus refinamentos.

## Crítico

### 1. `playing.py` continua concentrando responsabilidades demais

`PlayingScene` ainda reúne colisões, progressão de nível, boss fights, upgrades, input, cutscenes, HUD, transições de mundo, cheat codes e meta-progression. O risco não é teórico: qualquer mudança em uma área continua com chance de afetar várias outras.

**Impacto:** a cena segue difícil de testar, de manter e de evoluir. O próximo passo natural é extrair controladores de domínio.

**Direção recomendada:**
```python
class BossFightController:
    def start(self, boss_type, health_mult): ...
    def update(self, dt): ...
    def end(self): ...

class LevelProgressionController:
    def check_progression(self): ...
    def advance(self): ...

class ShootingSystem:
    def fire(self, ship, entity_manager): ...
```

## Médio

### 2. `config.py` ainda funciona como namespace global disfarçado

O arquivo concentra configurações de boss, formações, power-ups e UI em um único bloco. Funciona, mas não é uma modelagem saudável para crescimento do projeto.

**Direção recomendada:** separar por domínio.

```python
@dataclass(frozen=True)
class DisplayConfig: ...

@dataclass(frozen=True)
class GameplayConfig: ...

@dataclass(frozen=True)
class GameConfig:
    display: DisplayConfig
    gameplay: GameplayConfig
    bosses: BossConfigs
```
