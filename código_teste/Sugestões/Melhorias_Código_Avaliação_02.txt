# Code Review: Event Bus — Refinamentos

O Event Bus está totalmente integrado. Este arquivo registra os refinamentos aplicados após a implementação inicial.

---

## Corrigido

### 1. Duplicação de explosões
O handler legado de `EnemyDestroyed` foi removido de `EffectsSystem`. Explosões geridas centralizadamente via `EntityManager` ou evento `SpawnEffect`.

### 2. SoundSystem — métodos do gerenciador
`SoundSystem` usa exclusivamente os métodos expostos pelo `sound_manager`, garantindo consistência sonora.

### 3. Método `off()` no EventBus
`EventBus` possui suporte completo para remoção de handlers. `SoundSystem` e `EffectsSystem` chamam `off()` em `cleanup()`, prevenindo memory leaks.

### 4. Cores customizáveis em Floating Scores
`SpawnFloatingScore` aceita campo opcional `color`. `EffectsSystem` respeita o campo — a cena decide a cor sem lógica interna no sistema de efeitos.

### 5. Double-play do laser Magneto corrigido
`SoundSystem._on_player_shot` não mais toca `play_boss_laser_fire` para `projectile_type="cacador_laser"`. O canal é gerenciado diretamente em `playing.py` via `return_channel=True` e precisa de referência local para ser parado — não é substituível por evento.

### 6. Chamadas diretas de som migradas para eventos
- `sound_manager.play_warning()` → `emit(PlaySound("warning"))`
- `sound_manager.play_powerup()` em `_activate_stored_powerup` → `emit(PlaySound("powerup"))`

### 7. `LevelCleared` agora emitido
`_advance_to_next_level` emite `LevelCleared(level_number, score, time_taken)` após registrar a conclusão no perfil do jogador.

### 8. Eventos sem uso removidos
`ScoreGained` e `GameStateChange` removidos de `game_events.py` — nenhum emissor ou consumidor em lugar algum.

---

## Deliberadamente adiado

### HUD (Score/Combo) via eventos
Migrar o HUD para consumir `ScoreGained` exigiria re-introduzir o evento, criar um subscriber com estado próprio e desacoplar o renderer do scene state — redundância sem ganho real enquanto o HUD for renderizado diretamente em `playing.py`. Faz sentido após a extração do renderer como componente independente (relacionado ao item 1 do arquivo principal).
